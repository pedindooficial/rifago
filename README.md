# Rifago - Sistema de Gerenciamento de Rifas

Sistema completo para criação e gerenciamento de campanhas de rifa, similar ao Rifa123.

## Funcionalidades

- ✅ Criação de campanhas de rifa
- ✅ Gerenciamento completo de campanhas
- ✅ Cálculo automático de arrecadação e taxas
- ✅ Múltiplos tipos de sorteio (Loteria Federal, Sorteador, Deu no Poste, Organizador)
- ✅ Interface moderna e responsiva

## Tecnologias

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod (validação)

## Como executar

```bash
# Instalar dependências
npm install

# Executar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Executar produção
npm start
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.
